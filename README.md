# Onion Shop — сайт предзаказов из Китая

Готовый сайт без сборки и серверов: просто файлы. Работает на компьютере и телефоне, ставится на телефон как приложение.

## Что внутри

```
index.html              страница сайта
css/style.css           оформление (тёмная и светлая тема)
js/data.js              ВСЕ НАСТРОЙКИ: тарифы, сроки, уровни, задания, промокоды, контакты
js/app.js               логика сайта, аккаунты, кабинет
js/security.js          шифрование паролей и двухфакторная защита
js/qr.js                QR-код для подключения 2FA
js/globe.js             анимация глобуса на главной
assets/                 логотип и иконки приложения
assets/stickers/        сюда кладите свои картинки-стикеры
manifest.webmanifest    установка на телефон как приложение
sw.js                   работа без интернета
```

## Как выложить на GitHub Pages (бесплатно, без рекламных плашек)

1. Зарегистрируйтесь на [github.com](https://github.com) и нажмите **New repository**.
2. Название, например `onion-shop`. Тип — **Public**. Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** (или **Add file → Upload files**).
4. Перетащите **содержимое** этой папки: `index.html`, папки `css`, `js`, `assets` и остальные файлы. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Source: Deploy from a branch**, ветка **main**, папка **/ (root)**. Нажмите **Save**.
6. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/onion-shop/`.

Чтобы обновить сайт, загрузите изменённый файл в репозиторий тем же способом. Через минуту изменения появятся на сайте.

### Свой домен (например, onionshop.ru)

В **Settings → Pages → Custom domain** впишите домен и нажмите **Save**. У регистратора домена добавьте запись `CNAME` на `ВАШ-ЛОГИН.github.io`. Включите галочку **Enforce HTTPS**.

## Как поменять цифры и тексты

Откройте `js/data.js` (на GitHub — значок карандаша **Edit**). Там подписано, что за что отвечает:

- `dest` — тарифы и сроки по странам;
- `levels` — уровни: пороги очков, скидка на доставку (`delivery: 0.05` — это 5%), бонусы, личные промокоды;
- `orderXp` — сколько очков дают за заказ;
- `quests` — задания и награды;
- `promoCodes` — промокоды для канала (`WELCOME`, `ONION2026` — замените на свои);
- `demoEnabled` — показывать ли кнопку демо-кабинета;
- `contacts` — телефон и ссылки.

## Как поставить свои стикеры вместо иконок

1. Положите картинку в `assets/stickers/`, например `plane.png` (лучше PNG или WEBP с прозрачным фоном, 128×128).
2. В `index.html` найдите нужную иконку, например:
   `<span class="ico ico-lg"><svg class="i" aria-hidden="true"><use href="#i-plane"/></svg></span>`
3. Замените то, что внутри `<span>`, на картинку:
   `<span class="ico ico-lg"><img src="assets/stickers/plane.png" alt=""></span>`

Рамка и размер останутся прежними.

## Аккаунты: что важно знать

Регистрация, вход, двухфакторная защита, уровни, задания и промокоды работают прямо в браузере. Пароли хранятся только в зашифрованном виде (PBKDF2), коды 2FA совместимы с Google Authenticator и Яндекс Ключом.

Сейчас аккаунт хранится **на устройстве клиента**. Если клиент зарегистрировался на телефоне, на компьютере он войти не сможет, а вы не видите список клиентов и не можете начислять заказы. Чтобы аккаунты работали на всех устройствах, а заказы и уровни начислялись из вашей панели, нужен сервер (например, бесплатный Supabase). Код подготовлен к этому: вся работа с данными собрана в `js/app.js` в блоках «хранилище» и «аккаунты». Пока сервер не подключён, на странице входа показывается подсказка об этом (`accountsOnDeviceNote` в `data.js`).
